# 图片替换说明

把你的照片放在此文件夹，并使用以下文件名：

- `hero-cover.jpg`
- `wedding-01.jpg` / `wedding-01-large.jpg`
- `wedding-02.jpg` / `wedding-02-large.jpg`
- `portrait-01.jpg` / `portrait-01-large.jpg`
- `portrait-02.jpg` / `portrait-02-large.jpg`
- `experimental-01.jpg` / `experimental-01-large.jpg`
- `experimental-02.jpg` / `experimental-02-large.jpg`
- `event-01.jpg` / `event-01-large.jpg`
- `event-02.jpg` / `event-02-large.jpg`

列表图建议宽度 1200px；大图建议宽度 2400px。可在 `src/main.jsx` 的“图片替换区”修改路径或增加作品。
